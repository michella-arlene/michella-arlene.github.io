# Skills and tech stack

## Engineering stack

At WidaTech I build with TypeScript, Go, PHP (Symfony) and Python on the backend; React, Vue 3 and Flutter on the frontend and mobile; PostgreSQL and MariaDB for data; and Docker, GitHub Actions and GitLab CI for deployment. I also build LLM-powered assistants and automation with the Claude API, and use Playwright for browser automation and testing.

## Data, machine learning and AI

Python with Pandas, NumPy, Scikit-learn and Matplotlib/Seaborn; SQL and PostgreSQL; PyTorch; TensorFlow/Keras basics; NLP with spaCy and HuggingFace; OpenCV for computer vision; XGBoost for survival analysis.

## Cloud and tools

Microsoft Azure AI, Google Cloud (Colab), Jupyter, Git, Postman and Figma.
